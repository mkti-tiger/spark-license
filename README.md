## 概要

ソフトウェア、メディア、データ、AIモデル、ハードウェア起動許可等、ライセンス起動を要するあらゆるデジタル/物理資産に適用可能な汎用ライセンス管理プロトコル。

### 中核となる2つの要素

1. **期限・回収機能付きトークンベースライセンス**
   - ブロックチェーン上のトークンで期限管理
   - 発行者による回収（取り戻し）が可能
   - サブスク自動化、違反者の即時停止を実現

2. **秘密鍵埋込パスキー化**
   - 秘密鍵を暗号化して製品に埋め込み
   - 復号用パスキーをユーザーに渡す
   - ユーザーはブロックチェーンの存在を意識しない
   - 一般市場への展開が可能

## 設計の本質

### なぜブロックチェーンを表に出さないのか

ブロックチェーンを顧客に意識させると以下の心理的障壁が発生します:

- 「暗号資産?難しそう」
- 「ウォレット作るのが面倒」
- 「秘密鍵?怖い」
- 「税務処理どうなる?」

これらが障壁となり、一般顧客が逃げます。市場が暗号資産好きだけに極小化し、失敗します。

### パスキー化による解決

秘密鍵を暗号化して製品に埋め込み、復号用のパスキーを顧客に渡します。

- 顧客から見れば「普通のパスキー認証式ライセンス」
- 内部では秘密鍵を復号してブロックチェーン上のトークンを検証
- 顧客は暗号資産の存在すら知らない
- 一般市場に展開可能

### 法的整理のシンプルさ

- 顧客との契約は通常のソフトウェアライセンス契約
- 顧客は暗号資産を扱っていない（認識上）
- 暗号資産取引業の規制を回避できる
